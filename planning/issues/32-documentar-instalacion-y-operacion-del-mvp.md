# Documentar instalación y operación del MVP

Crear documentación para poder usar y mantener la aplicación sin depender del contexto de desarrollo.

## Criterios de aceptación
- Instalación local.
- Arranque.
- Importación de reportes.
- Uso del dashboard.
- Flujo de comunicaciones.
- Copias de seguridad y datos locales.
- Integración de nuevos cursos.
