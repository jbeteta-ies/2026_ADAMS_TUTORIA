# Diseñar entidades Course y Edition

Definir el modelo interno para cursos y ediciones.

## Criterios de aceptación
- Course representa un curso reutilizable.
- Edition representa una edición concreta de un Course.
- Se documentan relaciones y campos mínimos.
- El diseño admite varias ediciones del mismo curso.
- El diseño no depende de IFCT0138.
