# Definir contrato interno de importación

Crear un formato interno estable que desacople ADAMS del resto de la aplicación.

## Criterios de aceptación
- El resto de la aplicación no depende de columnas concretas de ADAMS.
- Se define validación de datos importados.
- Se contemplan errores y filas rechazadas.
- Se documenta cómo añadir nuevos adaptadores.
