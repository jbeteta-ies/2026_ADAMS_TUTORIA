# Generar recomendaciones de comunicación

Relacionar reglas de seguimiento con mensajes sugeridos.

## Criterios de aceptación
- Una alerta puede producir una comunicación sugerida.
- Se muestra por qué se recomienda.
- Se consulta el historial para evitar repeticiones excesivas.
- El tutor puede descartar o posponer la sugerencia.
