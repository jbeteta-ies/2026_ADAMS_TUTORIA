# Definir catálogo de tipos de comunicación

Definir los tipos de mensajes que el sistema podrá sugerir.

## Alcance inicial
- invitación a iniciar
- recordatorio por inactividad
- recordatorio de evaluación pendiente
- felicitación por evaluación superada
- ánimo tras resultado insuficiente
- felicitación por finalización

## Criterios de aceptación
- Cada tipo tiene propósito y condiciones claras.
- No se automatiza el envío.
- Se contempla tono personalizable.
