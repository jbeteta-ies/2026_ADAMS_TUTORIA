# Configurar calidad de código y tests

Configurar las herramientas base de calidad.

## Alcance
- pytest
- Ruff
- formateo
- mypy cuando sea práctico
- configuración centralizada

## Criterios de aceptación
- Existe un comando documentado para ejecutar tests.
- Existe un comando documentado para lint.
- Existe un comando documentado para comprobar formato.
- Existe un comando documentado para type-checking si se habilita.
- Todas las comprobaciones pasan sobre el proyecto inicial.
