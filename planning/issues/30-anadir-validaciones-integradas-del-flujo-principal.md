# Añadir validaciones integradas del flujo principal

Crear pruebas integradas del flujo de uso con datos sintéticos.

## Criterios de aceptación
- Importación sintética → persistencia → reglas → dashboard/comunicación.
- No requiere ADAMS real.
- Las pruebas son reproducibles.
- Fallos muestran información diagnóstica útil sin datos sensibles.
