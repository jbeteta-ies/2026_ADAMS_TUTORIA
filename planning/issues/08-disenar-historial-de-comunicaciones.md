# Diseñar historial de comunicaciones

Definir cómo registrar comunicaciones sugeridas, descartadas y enviadas manualmente.

## Criterios de aceptación
- Se registra tipo, fecha, destinatario, motivo y estado.
- Se puede evitar recomendar repetidamente el mismo mensaje.
- Se contempla revisión humana previa.
- No se presupone envío automatizado desde ADAMS.
