# Añadir flujo de copiar mensajes

Facilitar la revisión y copia manual de mensajes para ADAMS.

## Criterios de aceptación
- El mensaje se puede revisar antes de copiar.
- Existe una acción clara de copiado o selección fácil.
- Registrar como enviado requiere una acción explícita del tutor.
- No se envía nada automáticamente.
