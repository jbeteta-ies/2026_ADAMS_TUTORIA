# Inicializar estructura Python del proyecto

Crear la estructura base del proyecto Python sin implementar todavía lógica de negocio.

## Alcance
- Definir versión objetivo de Python.
- Elegir y documentar gestión de dependencias.
- Crear estructura de paquetes.
- Preparar punto de entrada mínimo.
- Mantener la aplicación ejecutable en local.

## Criterios de aceptación
- Existe una estructura Python coherente y documentada.
- La versión de Python objetivo está fijada.
- Las dependencias se pueden instalar de forma reproducible.
- Existe un comando mínimo para verificar que el proyecto arranca.
- No se introduce lógica específica de IFCT0138.
