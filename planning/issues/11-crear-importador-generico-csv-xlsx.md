# Crear importador genérico CSV/XLSX

Crear un importador configurable para ficheros tabulares antes de disponer de ejemplos reales.

## Criterios de aceptación
- Puede leer CSV y/o XLSX de prueba sintéticos.
- Valida columnas requeridas configurables.
- Informa de filas aceptadas y rechazadas.
- No registra datos personales completos en logs.
