# Preparar adaptador de seguimiento ADAMS

Preparar la importación de reportes de seguimiento sin inventar el formato real.

## Criterios de aceptación
- Se define interfaz/adaptador.
- Se soportan fixtures sintéticos.
- No se codifican nombres de columnas no confirmados como si fueran definitivos.
- La futura adaptación a un reporte real queda localizada.
