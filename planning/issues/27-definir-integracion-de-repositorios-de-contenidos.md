# Definir integración de repositorios de contenidos

Definir cómo asociar un Course con un repositorio o ruta local de contenidos Markdown.

## Criterios de aceptación
- La aplicación admite distintos cursos.
- La ruta/repositorio se configura por curso.
- No se duplica obligatoriamente el contenido.
- No se acopla la aplicación a IFCT0138.
