# Proteger datos locales y secretos

Establecer las protecciones de repositorio necesarias antes de trabajar con datos reales.

## Alcance
- Revisar `.gitignore`.
- Proteger bases de datos locales, exports, `.env` y directorios de datos.
- Crear ejemplos sintéticos cuando sea necesario.
- Documentar qué nunca debe subirse a GitHub.

## Criterios de aceptación
- Los patrones de datos operativos quedan ignorados por Git.
- Se documenta la política de datos locales.
- No hay datos personales reales en el repositorio.
- Se añaden tests o verificaciones razonables si aportan valor.
