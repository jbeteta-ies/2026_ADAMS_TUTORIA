# Registrar comunicaciones y acciones del tutor

Permitir registrar que un mensaje se copió/envió manualmente, se descartó o se pospuso.

## Criterios de aceptación
- El historial queda persistido.
- Se registra fecha y estado.
- El sistema puede usar ese historial en futuras recomendaciones.
- No se requiere integración con credenciales de ADAMS.
